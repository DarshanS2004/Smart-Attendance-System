# Models

Place runtime model assets in these folders:

- `models/yolo/yolov8n-face.pt` for YOLO face detection
- `models/embeddings/facenet_embeddings.pkl` generated by the enrollment script

The project will automatically use `facenet-pytorch` pretrained FaceNet weights.
If the YOLO face model is missing, the camera pipeline falls back to OpenCV Haar cascade so the project can still run during initial setup.
